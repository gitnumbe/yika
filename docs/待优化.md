## 1. 前端 Element Plus 全量引入（chunk 过大）
- **现象**：`frontend-vue` 构建后 `index-*.js` 单 chunk 约 **1.16 MB**（gzip 364 KB），超过 500KB 触发警告。
- **根因**：`src/main.ts` 用 `app.use(ElementPlus)` 全量注册 + 注册全部 `@element-plus/icons-vue` 图标，打包未按需。
- **影响**：仅首屏加载略重，功能不受影响（P2/P3 验收已过）。
- **建议方案**（后续做）：
  - 改用 `unplugin-vue-components` + `unplugin-auto-import` 按需引入 Element Plus 组件；
  - 图标只注册用到的，或保留全量但拆包。
- **触发批次**：P7 前端业务页开发前后均可，建议 P7 前做（P7 会新增大量业务页面，按需引入收益更大）。
